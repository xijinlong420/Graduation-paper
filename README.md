## 当前研究兴趣（尚未定题）

网络梗图/网络迷因、歧视识别、歧视性幽默、青少年同伴规范、同伴互动、校园欺凌与旁观者保护行为。贵州初中生是优先考虑的样本方向，但具体地区、年级、样本渠道和研究对象均待确认。

## 研究诚信与隐私

1. 不编造文献、DOI、量表、数据、统计结果或研究结论。
2. 优先核查原始论文、正式出版页面和补充材料。
3. 明确标记事实、原文报告、推论、假设和待核实事项。
4. 不把相关关系写成因果关系。
5. 未成年人研究须先确认伦理审批、监护人同意、学生同意/赞同及学校许可要求。
6. 本仓库为公开仓库：严禁提交可识别个人身份的研究数据、未成年人原始数据、联系方式、知情同意书或其他敏感材料。
7. 原始数据应存放在学校批准且访问受控的存储空间；仓库仅保存脱敏模板、代码和不含敏感信息的研究文档。

## 工作流程

选题审查 → 文献证据矩阵 → 构念与理论 → 研究问题/假设 → 测量与研究设计 → 伦理与预测试 → 数据分析 → 论文写作 → 模拟审稿。

所有重要决策应记录在 `00_RESEARCH_DASHBOARD/research-decisions.md`。不要在研究问题和方案尚未成熟时进行预注册或锁定最终模型。
