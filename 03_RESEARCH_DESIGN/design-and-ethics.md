# 研究设计与伦理检查清单

## 研究设计
- [ ] 研究问题与主要结局变量明确
- [ ] 研究类型、时间结构和分析单位明确
- [ ] 样本量依据与招募方式说明
- [ ] 纳入/排除标准预先确定
- [ ] 测量工具来源、授权、翻译/修订程序核实
- [ ] 刺激材料来源、筛选、编码和预测试程序明确
- [ ] 共同方法偏差、社会赞许性和需求特征有应对方案
- [ ] 缺失数据、异常值和排除规则预先制定

## 未成年人研究
- [ ] 向导师/学校确认适用的伦理审查流程
- [ ] 获得正式伦理批准（如适用）
- [ ] 获得学校/机构许可
- [ ] 监护人知情同意流程明确
- [ ] 学生本人知情同意/赞同流程明确
- [ ] 参与自愿、可退出且不影响学业评价
- [ ] 对歧视、欺凌等敏感内容提供适当风险控制与求助信息
- [ ] 数据去标识化、访问权限、保存期限和销毁方式明确

## 数据安全
本仓库公开。不得上传原始问卷、学生个体数据、可识别学校/班级组合、联系方式、签名或同意书。仅可提交经审查的空白模板、分析代码和不含敏感信息的汇总结果。
