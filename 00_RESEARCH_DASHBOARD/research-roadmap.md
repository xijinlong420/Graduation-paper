# 科研总览与两个月冲刺路线

## 项目目标
在本学期剩余约两个月内，形成一份可交导师讨论的小论文初稿，或一份结构完整、证据充分的研究方案。正式投稿时间取决于选题、伦理审批、样本和数据质量，不作时间保证。

## 当前主题池（均未定题）
- 网络梗图/网络迷因与青少年社会判断
- 歧视识别与歧视性幽默
- 同伴规范、同伴互动与群体影响
- 校园欺凌及旁观者反应/保护行为

优先考虑贵州初中生，但样本渠道、地区、年级和伦理审批状态尚未确认。

## 里程碑
| 阶段 | 目标交付物 | 通过标准 |
|---|---|---|
| 第1周 | 候选题与近年文献证据矩阵 | 关键文献可追溯；明确已有研究覆盖范围 |
| 第2周 | 研究空白审查与定题备忘录 | 创新点不是简单换地区/样本；至少有可辩护的理论问题 |
| 第3周 | 构念定义、理论比较、概念模型 | 构念可区分；理论链条有原始研究支持 |
| 第4周 | 研究问题、假设与设计草案 | 每个假设对应可检验变量和分析 |
| 第5周 | 测量/刺激材料与伦理文件草案 | 量表来源、授权、适配和未成年人保护明确 |
| 第6周 | 预测试或可行性评估 | 不以未经批准的方式招募未成年人 |
| 第7周 | 分析计划与论文初稿框架 | 方法、变量和分析相互一致 |
| 第8周 | 完整初稿/研究方案及模拟审稿 | 限制、替代解释和待补证据明确 |

## 关键决策门
1. 是否能在两个月内合规接触目标样本？
2. 是否已获得学校/导师要求的伦理审批和许可？
3. 研究问题是否与现有研究有实质差异？
4. 测量工具是否适用于目标年龄与语言文化情境？
5. 若实证条件不成熟，是否及时转为系统综述/范围综述或研究方案，而不是仓促收集低质量数据？

## 工作原则
每天完成一个可交付的小任务。助手可承担检索、证据整理、文档搭建、代码和写作初稿；研究者须对选题判断、伦理、招募、数据真实性和最终解释负责。
